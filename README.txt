# Tejas Static Website

This is a static adaptation of the supplied WordPress theme.

Files:
- index.html — main website
- thank-you.html — lead conversion page
- style.css — styling
- script.js — button/event behavior

Meta Pixel:
- Pixel ID: 109080919388802
- PageView fires on both pages.
- AddToCart fires when a product button is clicked.
- Lead fires on thank-you.html.

Important:
This is a demo website. It does not process real payments or collect/store submitted form data.

Hosting:
Upload all four website files to a static host such as GitHub Pages, Netlify, or Vercel.
